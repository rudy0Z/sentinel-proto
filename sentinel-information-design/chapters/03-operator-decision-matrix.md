# 03 · On-Scene Operator Decision Matrix

FlytBase Sentinel console · desktop 1920×1080 · personas: Asha (primary Mission Operator), relief operator, regional commander.
Synthesis of R4 (operator-UX research), R2 (fleet/sensor feeds), and repo audit (`panels.ts` slot model, `GATED_ACTIONS`, tokens).
KPI anchor: detection → validated dispatch **48 min → 90 s**.

**Roles:** IC = Incident Commander · MO = Mission Operator (Sentinel console) · RPIC = Remote Pilot in Command.
**Phases:** Validate → Dispatch → Flight → On-scene → Containment → Mop-up (+ Cross-phase rows).
**Panel IDs** reference the component inventory in `07-ui-component-spec.md` (P1–P12 panels, C1–C9 components). Gates G1–G3 are defined in §2 below.
**Tags** `[S#]` / `[INF]` preserved from R4; rows marked *(repo)* are new, grounded in the in-repo state machine / TALON constitution rather than R4 sources.

## 2 · Human gates (explicit)

**Conflict resolution — 4 repo gates vs 3 console gates.** The repo (`talon.ts` `GATED_ACTIONS`) defines four gated actions: confirm-incident, notify-authorities, authorize-containment, emergency-evacuate. This specification surfaces **three operator gates on the action bar** — **G1 Confirm Incident**, **G2 Authorize Containment**, **G3 Emergency Evacuate** — because **notify-authorities is implemented as the staged AuthorityPacket** (drafting→ready→sent, expiry-never-executes) released from the G1 receipt and packet card (matrix row 8), not as a fourth bottom-bar hold. `console-wireframe.html` shows the three gates accordingly.

All three gates are **Class-3 controls: 2.0-second continuous press-and-hold** with a radial progress ring. Release before 100 % cancels (no partial execution); completion fires exactly once and writes an audit receipt.

| Gate | Repo action | Phase (90-s arc) | Data that MUST be shown before the gate unlocks | Completion semantics | Cancel / dissent |
|------|-------------|------------------|--------------------------------------------------|----------------------|------------------|
| **G1 Confirm Incident** | confirm-incident | Validate (15–45 s) | ≥2 corroborating sources with status `active` (e.g., thermal + drone-visual or GOES-R bloom); fused confidence ≥70 **and rising** (62→78→91 trajectory rendered as convergence bar); anomaly lat/long + UTC timestamp (03:47:03, Grid 4C); nearest-drone ETA (dock launch 45 s); authority-packet preview (agency, severity grade, missingData[]) | Creates incident; fires T1/T2 alert path; arms packet send (staged, row 8) | Release cancels silently; Dismiss instead requires reason code (glare / fog-dust / industrial / animal / other) feeding the tuning loop; dismissed alerts stay retrievable |
| **G2 Authorize Containment** | authorize-containment | On-scene→Containment (45–75 s) | Selected strategy (ridge-anchor / creek-buffer / defensive-holding) with baseline vs projected residual spread rate; uncertainty margin ±m (satellite loss widens ±200 m); structures in path / at residual risk (47); ghost-drone placements visible as PROPOSED on P1; route-a/route-b status (open/blocked); spread-projection age <5 min; simulation agent not `failed` | Ghosts→active; evacuation-guidance drones dispatch-ready; right rail switches to exception-only supervision | Release cancels; overriding the TALON recommendation requires reason capture (DissentGate) — dissent is never silent |
| **G3 Emergency Evacuate** | emergency-evacuate | Containment/Rescue (75–90 s) | Per-zone time-to-impact vs household prep+travel timeline; spread vector toward residential-south; zone status chips (W → GO); corridor open/blocked state (route-a / route-b); shelter sites; structures in scope (47); comms bridge to IC + ground teams live | Corridors render on P1; evac-guidance drones go active; unacked zone alerts escalate at 60 s | Release cancels; zone-level GO requires per-zone ack tracking; shelved alerts auto-unshelve |

**Staged fourth action:** notify-authorities travels as the AuthorityPacket (`AUD-90-0847 · ready · CAL_FIRE_NORTH`), Class-2: editable until sent, **expiry never executes**, every send/receipt logged to P9.

## 3 · Refresh-rate summary

Consolidated normative budget lives in `07-ui-component-spec.md` §4. Headlines: map position 1–10 Hz (≥1 Hz floor) [S21][S22]; video 24–30 fps @1080p, ≤250 ms glass-to-glass [S10][S11]; telemetry strip 1 Hz render (source broadcast 5–10 Hz); traffic/DAA ~1 Hz; weather display 1–5 min (RAWS obs hourly); perimeter per orbit; spread projection 5–15 min; alerts event-driven push, never polled.
