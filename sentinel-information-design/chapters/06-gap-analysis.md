## 3 · Repo strengths to keep

The gap analysis is additive — the following repo-enforced properties are the foundation the required design builds on, not items to rebuild:

- **Human gates.** `GATED_ACTIONS` = confirm-incident, notify-authorities, authorize-containment, emergency-evacuate [repo·`talon.ts` L44]; Class-3 **2.0-s press-and-hold** w/ radial ring, release = cancel, completion fires exactly once → receipt [repo·`ActionBar.tsx`, docs/04]; Class-2 staged actions **expiry-never-executes** [repo·docs/04].
- **Receipts.** Actor-tagged audit feed (AI/TALON/Operator/System + severity) [repo·`mockData.ts` ActivityLog]; authority-packet lifecycle drafting→ready→sent (AUD-90-0847 pattern); every override captured with reason (`OVERRIDE_REASONS`, `DissentGate.tsx`) — dissent never silent.
- **Exception model.** `OperationalException` schema with quantified `confidenceImpact` ("Confidence reduced to 40%. Spread margin increased ±200m"), `spatialUncertainty {marginMeters, affectedZoneIds, basis, observedAt}`, `blockedCommands`, `fallbackInputs`, `recommendedRecoveryCommand`, `auditText` [repo·`exceptions.ts`]; five documented failure scenes verified by `verify:machine` (31 transitions / 0 unreachable / 4 fault scenes).
- **Urgency-density.** "Urgency reduces density" is already the repo principle (PRODUCT.md anti-references) and `domain/panels.ts` is contextual by phase + exception — 07 §5 formalizes the shed order it implies.
- **Disagreement memory.** `shouldReRaise` re-raises only when new evidence crosses the raised bar [repo·`disagreement.ts`]; ContestedWatch / Reconciliation / ReRaiseBrief render the arc; dismissed alerts stay retrievable — the anti-nagging loop is already stateful.
- **Guardrails.** Truth guard (`FORBIDDEN_CLAIM_PATTERNS`, `FORBIDDEN_SOURCE_PATTERN`) + forbidden-by-construction tool set (send-authority-packet, authorize-containment, close-corridor, order-chemical-drop, notify-mutual-aid, abort-mission have no tool) [repo·`talonGateway.ts`, `talonTools.ts`]; 8-s LLM timeout falls back to authored microcopy so the console never strands.
- **Verification gates.** typecheck; verify:map 9/9; verify:flows 19/19; verify:routes 23/23; verify:machine 31 transitions / 4 fault scenes; verify:signals 16 scenes; eval:talon [repo·`package.json`] — the harness that makes the above claims checkable.
