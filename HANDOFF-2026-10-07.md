## Direction contract (owner-confirmed)

- **Two vertical rails** (left = operator, right = TALON, center orb = conversation)
- **Collapsed by default**: 4 left dots (intel, map, fleet, activity), 3+2 right dots (talon, priority, ground-teams + contextual investigation/exceptions)
- **Peek language**: T1/T2 panels flash open (~168px glimpse, ~1.6s) on revision bump, then dissolve back; respects INTERRUPT_BUDGET (≤2 pops/10min)
- **Dot pulse tiers**: T1 red alert (gate), T2 amber soft (exception), T3 cyan breathe (computing), fresh one-shot pop (revision bump), T4 muted
- **Gooey morphs**: panel opens with translateX from rail + opacity + radius 24→16, `ease.drawer` ≤240ms
- **Golden rules**: gates resolve via existing path (CommandTile hold → handleAction → modal); silence never approves; expiry is never execution; left never auto-opens; one panel per side

## Key invariants (do not violate)

- Gates only resolve via CommandTile hold → handleAction → ActionModal/dispatch
- Rule of One: orb is the interrupting surface; dots/peeks are badges
- All TALON data derives from `domain/talon.ts` (chat, orb, deck never disagree)
- One panel per side; left never auto-opens
- a11y: every dot = labelled tab, every panel = labelled region; axe must stay clean; zero console errors
- All pulse/glow in CSS (hyphenated `box-shadow`), not inline TS — audit:tokens hard-fail on inline glow
