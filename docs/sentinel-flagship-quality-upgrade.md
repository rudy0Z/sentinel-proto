## 0. Thesis, audience, non-goals

**Thesis.** Sentinel compresses the time to a defensible first escalation decision from 15 minutes to under 90 seconds, then becomes a supervised tactical coordination surface. TALON is a reasoner strapped to a constitution: the state machine validates, the human authorizes, the LLM never acts directly. If the model is fully hijacked, the worst case is a weird voice — never a wrong action.

**Two reviewers, one artifact.** (1) Product designer: every state legible, every blocked action explained, every AI action inspectable, failures with real exits. (2) AI builder: permissioned tool layer over a formal machine, derived (not free-form) voice, structural refusals/re-raises/uncertainty, an eval harness.

**Non-goals (locked).** No FlytBase API integration. No fire-trained-AI claims — TALON is a general LLM in a domain tool harness; the honesty boundary travels on every surface (entry badge, `live-ai`/`scripted` labels, case-study disclosure). No multi-incident command, no offline continuity, no mobile variants in this plan.

**Numbers lock.** Baseline "15 minutes" everywhere. Spread rings are 15/30/60 **min** (never "m"). No stage/route counts claimed without derivation — authority is "every scene/edge enumerated in §5 with machine parity."
